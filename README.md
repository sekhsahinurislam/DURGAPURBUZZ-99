DURGAPUR BUZZ – Admin update

Changes:
- Removed the short-description/excerpt input from the Admin news form.
- News saving no longer asks for or translates a short description; legacy excerpt fields are set empty for new/updated posts.
- Added an optional Facebook News/Post URL field in Admin. On the full article page, readers get a button to open the original Facebook post.
- Added a footer credit “Design by Sahinur Islam” linking to the Instagram profile supplied by the site owner.

Deploy:
1. Extract this ZIP.
2. Replace the repository root index.html with this index.html.
3. Commit the change and wait for GitHub Pages to publish.

Note: The Facebook URL is stored as a link to the original post; it does not automatically import Facebook post text or embed content. Enter the news headline and full story in the normal fields as well.
